# LMP｜あの日の夢に、今の武器を。

ライフメイクパートナーズ（LMP）の加盟訴求ランディングページ。
賃貸仲介・管理会社の経営者に向けて、創業時の想いを起点に加盟を訴求する構成。

**公開URL:** https://nrealize6078-hue.github.io/lmp-origin-dream-lp/

## 構成

ビルド不要の静的サイトです。`index.html` をブラウザーで開けばそのまま確認できます。

| ファイル | 役割 |
|---|---|
| `index.html` | ページ全体（HTML・CSS・JS とも1ファイルに収録） |
| `origin-hero.jpg` | ファーストビューの背景写真 |

CSSは `index.html` 内の `<style>`、JavaScript は末尾の `<script>` にまとめてあります。
外部ファイル・外部フォントは使っていないため、この2ファイルだけで完結します。

## 編集のしかた

### 文章を直す
`index.html` の `</style>` より下が本文です。該当の文字列を探して書き換えます。

### 色を変える
`<style>` 冒頭の `:root` にある CSS変数を書き換えると全体に反映されます。

| 変数 | 用途 |
|---|---|
| `--ink` | 基本の文字色 |
| `--blue` | アクセント（ボタン・見出しの強調） |
| `--lime` | サブアクセント |
| `--paper` | 背景のベース色 |
| `--line` | 罫線 |

### ヒーロー写真を差し替える
`origin-hero.jpg` を同名で上書きします。CSSの `background` から参照しています。

### CSSの構造について
セクションごとに `/* ---- ヒーロー ---- */` のようなコメントで区切ってあります。
1セレクタ＝1箇所で定義されているので、同じセレクタを探し回る必要はありません。
レスポンシブ指定（`@media`）はすべてファイル末尾にまとめてあります。

## 問い合わせ導線

LINE公式アカウントに一本化しています（最終CTAのカード＋固定ボトムバーの2か所）。
リンクの変更は `index.html` 内の `https://lin.ee/vV1leDB` を全置換してください。

LINE公式の「友だち追加」画像が読み込めない環境では、同じリンクを持つ
ブランドカラーのボタンへ自動で差し替わります（末尾の `<script>` が処理）。

固定ボトムバーはヒーローを通過した時点でせり上がります。表示切替は
`.cta-bar` の `is-visible` クラスで、バーの高さは CSS変数 `--bar-h` です。

### 注意

`hidden` 属性は CSS の `display` 指定に負けます。本LPでは CSS冒頭に
`[hidden]{display:none!important}` を入れて回避しています。新しく要素を
足すときも、この指定を消さないでください。

## スマホ表示について

日本語の改行が語の途中で切れないよう調整してあります（320〜768pxで確認済み）。

| 対象 | 方式 |
|---|---|
| 見出し（h1 / h2 / h3） | `min(元の指定, ○vw)` で画面幅に応じて縮小し、`<br>` の改行位置を保つ |
| 本文の段落 | `word-break:keep-all` で、折り返しを句読点の位置に寄せる |
| 課題カード | 480px以下は1カラム（2カラムのままだと見出しが11px台まで縮むため） |

### 触るときの注意

- `min()` の中の `vw` の値は **320px幅で実測**して決めています。文章を長くすると
  収まらなくなるので、文言を変えたら320px・375px・414pxで見え方を確認してください
- `word-break` を `body` 全体に掛けないでください。狭い2カラムの中で折り返せなくなり、
  **横スクロールが発生します**。対象の段落だけに限定しています
- 文字サイズの下限は12pxにしてあります
